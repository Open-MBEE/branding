# OpenMBEE brand assets

Designed by Robert Sheppard (Robert Sheppard Design Limited). Delivered 2026-11-01.
The full guidelines are in [`guidelines/OpenMBEE_brandguidelines.pdf`](guidelines/OpenMBEE_brandguidelines.pdf).

## Layout

```
openmbee/
├── guidelines/   brand guidelines PDF
└── logo/
    ├── svg/      vector masters (use these where possible)
    ├── png/      raster, RGB
    └── jpg/      raster, RGB
```

## Logo variants

| File | Use |
|---|---|
| `openMBEE_logo_landscape` | Primary horizontal lockup |
| `openMBEE_logo_square` | Primary stacked lockup |
| `openMBEE_logo_square_singlecolour` | Single colour, no gradients, **white backgrounds only** |

- The primary logo works best on a black background.
- The icon can be used on its own for social media, app icons, or low-key branding such as presentation footers.
- Clear zone: leave space around the logo equal to the height of the text plus the gap between text and icon.
